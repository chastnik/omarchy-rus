# Список изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Новые изменения копятся в разделе «Не выпущено», перед выпуском он переименовывается в номер версии с датой: `## [1.4.0] — 2026-10-10`.
Релиз по тегу берёт текст этого раздела в описание релиза и не собирается, если раздела для тега нет.

## [2.1.0] — 2026-11-12

### Добавлено
- Живой установщик (`ui.sh`): баннер, спиннер с таймером и последней строкой вывода у каждого шага, общий прогресс,
  клавиша `v` разворачивает вывод, журнал в `~/.local/state/omarchy-rus/install-*.log`, у упавших шагов —
  хвост вывода и команда для повтора. `--plain` (или запуск без терминала) — прежний вывод; `RUS_NO_ANIM=1`, `NO_COLOR=1`.
- CI: проверка модулей и таблиц README по смыслу (`tests/check-modules.py`), смоук-тест установщика в псевдотерминале
  (`tests/ui-smoke.sh`), сборка релизного архива в каждом PR, ruff, actionlint, проверка словаря эмодзи;
  еженедельная проверка внешних ссылок (`links.yml`).

### Исправлено
- Модули `spell`, `office`, `browsers`, `telegram`, `tts` ставят пакеты через sudo, но не были помечены `sudo: yes`:
  при `--only` пароль не спрашивался заранее.

## [2.0.0] — 2026-11-10

Omarchy 4.5: интерфейс переводит сам Omarchy (`omarchy language ru`, каталоги `/usr/share/omarchy/default/i18n/ru/`
для меню, бара и панелей, Super+K, уведомлений и About). omarchy-rus больше не держит параллельный перевод и
дополняет встроенную локализацию тем, чего в ней нет. Несовместимо с Omarchy до 4.5 (для них — 1.5.0).

**Обновление с 1.x:** сначала `omarchy update` до 4.5+, затем `./install.sh` с «Рекомендуемым» и перезаход в сессию.
Модуль `migrate` уберёт старый перевод, клоны сети, погоды и эмодзи пересоздадутся на прежних местах с прежними настройками.

### Добавлено
- Модуль `migrate`: убирает остатки 1.x — расширение меню, свои меню Super+K (блок в `~/.config/hypr/bindings.lua`
  и скрипты в `~/.local/bin`), сгенерированный конфиг fastfetch, все клоны плагинов 1.x (`omarchy plugin remove`
  возвращает оригиналы на место в баре; network, weather и emojis затем пересоздают их модули) и старый хук
  post-update, который после каждого `omarchy update` вернул бы русское меню. Трогает только созданное omarchy-rus.
- `install.sh` останавливается на Omarchy без встроенной локализации (до 4.5) и предлагает omarchy-rus 1.5.0.
- Модуль `emojis`: поиск эмодзи по русским названиям (раньше входил в `panels`).

### Изменено
- `locale` включает встроенный перевод: `omarchy language ru`.
- `translate-plugins.py` ведёт только три клона: `network` (DNS), `weather` (поиск города на языке интерфейса вместо
  жёсткого `language=en`), `emojis` (русские ключевые слова). Строки в клонах берутся из каталогов Omarchy.
- `dns-ru.py`: подсказки пилюль DNS берутся из каталога Omarchy (`I18n`) и следуют выбранному языку.
- `post-update-hook` только проверяет, не изменились ли оригиналы клонов.
- `translate-plugins.py`: клон 1.x пересоздаётся сам (список `v2` в `clones.json`); `omarchy plugin clone/remove`
  повторяются, пока шелл после перезагрузки не ответит; `--refresh` убирает клон через `omarchy plugin remove`,
  а не удалением папки, чтобы бар не ссылался на пустое место.

### Удалено
- Модули `menu`, `keybindings`, `panels`, `fastfetch`; скрипты `translate-menu.py`, `keybindings-ru.py`, `check-i18n.py`;
  словари `data/notifications-ru.json`, `data/i18n-ignore.txt` — всё это теперь делает Omarchy.

## [1.5.0] — 2026-10-25

Совместимость с Omarchy 4.0.5–4.0.6 (апстрим переехал на `omacom/omarchy`).

### Изменено
- Agents: панель в Omarchy 4.0.5 переписана (один агент на экране, секции «Баланс», «Лимиты», «Токены по дням»,
  «Токены по моделям»); словарь и правки `PATCHES` переделаны под новый интерфейс: заголовки секций, дни недели,
  подсказки токенов, баланс («потрачено … из …»), склонение «запросов»/«сессий», порядок «день.месяц».
- Уведомления: добавлены «Shutdown failed» и «Could not complete shutdown. Please try again.».

### Исправлено
- `check-i18n.py` не замечал заголовки капсом («BALANCE», «TOKENS BY DAY») и многострочные литералы с `\n`;
  теперь такие строки считаются непереведёнными. Пилюли DNS4EU добавлены в `data/i18n-ignore.txt`.

## [1.4.0] — 2026-10-04

### Добавлено
- `check-i18n.py`: проверка полноты перевода. Находит непереведённые пункты меню, тексты уведомлений, английские строки
  в клонах плагинов и «мёртвые» правки `PATCHES`; `--strict` для скриптов, `--notify` для уведомления.
  Исключения (бренды, технические значения) — в `data/i18n-ignore.txt`.
- Перевод уведомлений Omarchy (скриншоты, запись экрана, батарея, время, погода, переключатели, first-run и др.):
  словарь `data/notifications-ru.json`, переводится при показе карточки и в истории.
- `translate-plugins.py --check [--notify]` и `--refresh [имя …]`: обнаруживают клоны плагинов, чей оригинал изменился
  после `omarchy update`, и пересоздают их (с повторным применением DNS-правки для виджета сети).
- Модуль `browsers`: русский интерфейс и `Accept-Language` для Chromium/Brave/Chrome, языковой пакет Firefox.
- Модуль `piper` (необязательный): нейросетевой русский голос Piper (Irina), команда `say-ru`, модуль speech-dispatcher.
  Если AUR недоступен, ставится ранее собранный пакет из кэша yay.
- Склонение по числу: «1 напоминание / 2 напоминания / 5 напоминаний», «N файлов», «N устройств».
- Хук после обновления теперь проверяет устаревшие клоны и непереведённые строки и присылает уведомление.

### Изменено
- Переводы: «Prepaid credits», «Resets in», «Limit» (Agents), «Audio» (звук), «Ping» (сеть), «Shell» и геймпады Xbox в меню.

### Исправлено
- Удалены устаревшие правки панели Agents: в новой версии Omarchy этих строк уже нет.
